# Best Bike Natal — conceito de catálogo

Protótipo visual mobile-first baseado na estrutura do [VÉLO](https://oluisvi.github.io/velo-mobilidade/).

- Categorias confirmadas: scooters, triciclos e e-bikes.
- A orientação considera passeio, trabalho ou lazer e a autonomia necessária ao trajeto.
- Fotos e fichas são ilustrativas; modelos, autonomia, preço e estoque a confirmar.
- GitHub Pages publica `dist/` pelo workflow incluso.
